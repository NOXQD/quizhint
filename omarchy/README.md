# Quiz Hint — плагин для панели Omarchy

Значок-лампочка на панели управляет программой [quizhint](../README.md): по горячей клавише она снимает экран,
спрашивает vision-модель и показывает в углу экрана номер правильного ответа маленькой цифрой — или короткий
полный ответ текстом.

- **F1** (настраивается) — спросить про весь экран.
- **F3** (настраивается) — выделить мышью участок экрана и спросить только про него. Повторное F3 или Esc — отмена.

- **Клик** — панель: включатель, последний ответ (полный можно скопировать), режим ответа «Цифра / Полный»,
  Claude или Gemini, модель и ключ API, что снимать, где показывать ответ, горячие клавиши.
- **Средняя кнопка** — включить или выключить.

Кнопка **«Настройки»** внизу панели открывает страницу, где всё настраивается под себя: угол экрана и отступы,
размер цифры и текста ответа, ширина и число строк, через сколько секунд прятать, цвета текста и фона, плотность
фона, шрифт, длина ответа (короткий, средний, подробный), пояснение, язык ответа, свои указания модели, уровень
рассуждений, качество снимка и таймаут. Кнопки «Пример цифры» и «Пример ответа» сразу показывают результат на экране.

Экран снимается **только по горячим клавишам** — ни значок, ни панель снимок не запускают.
Пока плагин включён, он сам держит quizhint в фоне и сам назначает клавишу через Hyprland: прописывать что-то
в `bindings.lua` и `autostart.lua` не нужно.

| Значок | Значение |
|--------|----------|
| лампочка с лучами | работает |
| лампочка без лучей, тусклая | выключен |
| мигает | модель думает |
| красная | нужна настройка (например, ключ API) или запрос не удался — подробности в панели |

Настройки лежат в `~/.config/quizhint/config`, кнопка «Открыть конфиг» открывает его в редакторе. Правки файла
подхватываются сами: плагин перезапускает quizhint с новыми настройками.

## Установка

Из каталога проекта:

```sh
make install install-plugin
omarchy plugin enable noxqd.quizhint
```

Затем нажмите на лампочку, выберите Claude или Gemini, вставьте ключ в поле «Ключ API» и нажмите Enter
(ссылка под полем ведёт на страницу, где выдают ключ). Ключи хранятся отдельно для каждого провайдера.

Удаление: `make uninstall-plugin uninstall`.
