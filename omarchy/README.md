# Quiz Hint — плагин для панели Omarchy

Значок-лампочка на панели управляет программой [quizhint](../README.md): по горячей клавише она снимает экран,
спрашивает vision-модель и показывает номер правильного ответа маленькой цифрой в углу экрана.

- **Клик** — панель: включатель, последний ответ, Claude или Gemini, модель и ключ API, что снимать, где показывать
  цифру, горячая клавиша.
- **Средняя кнопка** — включить или выключить.

Экран снимается **только по горячей клавише** (по умолчанию F1) — ни значок, ни панель снимок не запускают.
Пока плагин включён, он сам держит quizhint в фоне и сам назначает клавишу через Hyprland: прописывать что-то
в `bindings.lua` и `autostart.lua` не нужно.

| Значок | Значение |
|--------|----------|
| лампочка с лучами | работает |
| лампочка без лучей, тусклая | выключен |
| мигает | модель думает |
| красная | нужна настройка (например, ключ API) или запрос не удался — подробности в панели |

Настройки лежат в `~/.config/quizhint/config`, кнопка «Открыть конфиг» открывает его в редакторе. Правки файла
подхватываются сами: плагин перезапускает quizhint с новыми настройками.

## Установка

Из каталога проекта:

```sh
make install install-plugin
omarchy plugin enable noxqd.quizhint
```

Затем нажмите на лампочку, выберите Claude или Gemini, вставьте ключ в поле «Ключ API» и нажмите Enter
(ссылка под полем ведёт на страницу, где выдают ключ). Ключи хранятся отдельно для каждого провайдера.

Удаление: `make uninstall-plugin uninstall`.
